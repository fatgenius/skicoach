# 第五课材料使用说明

1. 先看《后刃推坡 三IMU检测标准》PPT，再按 Word 讲义操作。
2. Arduino IDE 打开 `SkiCoach3IMU/SkiCoach3IMU.ino`。同目录的 `Posture.h` 会一起编译。选择实际 ESP32 开发板和端口。
3. 三枚 IMU 使用同一热点和 UDP 目标。初始配置为热点 SKI-COACH、密码 ski12345、目标 192.168.10.1:1399。三枚均设为目标 50 Hz。
4. 串口用 921600，发送换行符。单独上电并转动各 IMU，从 R 或 DISCOVER 核对 ID。修改 DEVICE_ID 数组，填入真实腰部编号，再烧录。每个 ID 只分配给一个部位。
5. 对照讲义检查各自 X/Y/Z 轴和方向。修改 sketch 顶部的轴映射与符号，再烧录。腿部两枚绑在同一侧。
6. 发送 CAL 并站直保持静止，等 CAL_OK。先看 K。台架模拟时发送 START 才会输出 W 及事件 E，STOP 停止事件。上雪阶段先记录，实时振动或蜂鸣反馈留到验证以后。

## 串口记录

| 前缀 | 字段顺序 |
|---|---|
| R | 接收时间 ms、部位 T/S/W、设备 ID、X/Y/Z 角度 |
| K | 接收时间 ms、大腿段角、小腿段角、膝屈曲角、接收时差 ms |
| W | 接收时间 ms、腰部前后倾、腰部左右倾、1 秒波动 W |
| E | 接收时间 ms、事件名称、触发读数 |
| STATUS | 设备上线、掉线、置零和监测段状态 |
| DISCOVER | 接收时间 ms、当前未分配的设备 ID |

所有角度单位为度。记录类型各有自己的字段。保存串口文本后，可以按前缀筛选并用 WPS 按逗号分列。可用串口工具的日志功能保存原文，上传程序前先释放 COM 口。

## 软件测试

有 g++ 的终端中运行下面两条命令。Windows 也可在 MinGW 环境编译成 test_posture.exe 后运行。

```sh
g++ -std=c++11 -Wall -Wextra -pedantic tests/test_posture.cpp -o test_posture
./test_posture
```

设备 UDP 帧按第 4 课资料中的 54 字节布局编写，串口应先验收真实三个 ID 和三轴角度。ESP32 接收时刻用于近似配对，发在同一个 UDP 报文里的帧共用接收时间。此包提供独立教学 sketch，雪上标定和三路实机验收按测试单完成。
